We Care For You

Healthcare Web Application

Project Description

We Care For You is a healthcare-based web application designed to provide users with basic health guidance and personalized recommendations. The system helps users understand common health problems and provides suitable home remedies, doctor recommendations, and food recommendations based on their health requirements.

The main objective of the project is to make basic healthcare information easily accessible through a simple and user-friendly platform.

Key Features

  • Health Problem Identification – Users can enter their health problems or symptoms.
  • Home Remedies – Provides suitable remedies for common health issues.
  • Doctor Recommendation – Suggests appropriate doctors or specialists based on the health problem.
  • Food Recommendation – Recommends suitable foods based on the user's health condition.
  • Health Tips – Provides useful health and wellness suggestions.
  • User-Friendly Interface – Simple design that allows users to easily access the required information.

Tools & Technologies Used

HTML CSS JavaScript Python MySQL VS Code Google Chrome

Personal Finance Planning Agent

Financial Advisor

Project Description

Personal Finance Planning Agent is a web-based financial management application designed to help users manage their personal finances in a simple and organized way. The system allows users to securely manage their income and expenses, set monthly budgets, create savings goals, and monitor their financial progress.

It also analyzes the user's financial data and provides AI-based recommendations to improve spending and saving habits. A dashboard with charts and reports gives users a clear view of their overall financial status.

Key Features

  • User Authentication – Secure registration, login, logout, password protection, and session management.
  • Income Management – Add, edit, delete, and track different sources of income.
  • Expense Management – Record and categorize daily expenses such as food, travel, rent, shopping, etc.
  • Budget Planning – Set monthly budgets and monitor spending against the planned budget.
  • Savings Planning – Create savings goals, set target amounts, deadlines, and track progress.
  • AI Recommendation – Analyze income and spending patterns and provide personalized financial suggestions.
  • Reports & Dashboard – Display total income, expenses, balance, savings, and graphical reports using charts.
  • Responsive Interface – Simple and user-friendly interface that works across desktop, tablet, and mobile screens.

Technologies Used

HTML5 CSS JavaScript Python Flask MySQL Chart.js Flask Session VS Code
